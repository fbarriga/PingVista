
**Full description** (4,000 characters maximum)

```text
PingVista is a focused network latency tool for checking how quickly your device can reach hosts and services.

Run ping tests over ICMP, HTTPS, TCP, or UDP/STUN. Choose a built-in target or enter your own host, URL, or STUN server, then see each result as it arrives.

Features:
• ICMP echo requests with configurable packet size, IPv4 TTL, and IPv6 hop limit
• HTTPS request timing after a warm-up request
• TCP connection handshake timing
• UDP round-trip timing with STUN
• IPv4 and IPv6 testing where supported
• Configurable test count and delay between pings
• Live ping results, latency histogram, detailed statistics, and graph
• Average, minimum, maximum, median, p90, p95, and p99 statistics
• ICMP packet loss and protocol-specific request failure rates
• Network interface addresses and external IP information

PingVista is useful for diagnosing slow or unstable connections, comparing networks, and checking reachability to a host or service.
```
